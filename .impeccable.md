# Design context

English-speaking learners exploring ancient architecture and source languages. Preserve the architectural engraving character described in docs/design.md: cool marble, graphite, Egyptian blue for selected parts, minium for measurements, GFS Didot and EB Garamond. User explicitly asks for distinctive, consequential, source-grounded learning rather than generic showcases. This audit makes source prescriptions and drawing assumptions operable and inspectable, with retained Latin pages and portable readings. Native controls, visible keyboard focus, small-screen legibility, and offline operation matter. Source excerpts, modern calculations, and illustrative choices must remain distinguishable. No ornamental dashboard or invented archaeological reconstruction.
