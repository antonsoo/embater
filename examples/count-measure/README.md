# A count supplies no dimensions

Actual downloads from the local production build, Chromium desktop, light theme.
The selected record is Selinus Temple C; the count reading doubles spaces; the
measuring trial takes the record's 6 × 17 count. Both axial pitches are 3 D,
the platform margin is 1 D beyond shaft faces, and the selected ruler measures
outside shaft faces. Its ratio is 49/16 = 3.0625. None of these distances are
attributed to the building.

- `trial.svg`: independently usable drawing with settings and model metadata.
- `trial.csv`: all three rulers, with unrounded measurements and chosen pitches.
- `reading.html.gz`: full script-free reading, source page, fonts, licenses and
  native CSV/SVG downloads. Decompress and open locally:

  ```sh
  gzip -dc examples/count-measure/reading.html.gz > /tmp/embater-count-reading.html
  ```

- `reading.pdf`: four-page A4 Chromium print of that reading. The illustrated
  trial and complete source page were inspected after rasterization.
- `manifest.json`: exact file lengths and SHA-256 values for this capture.

The HTML's reopen link targets the canonical app URL with all choices. This
extension has not been published; the live app may not yet understand its new
measurement fields. The local file and its embedded native downloads need no
connection. External source links require one.
