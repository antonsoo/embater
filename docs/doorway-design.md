# A doorway, read in two ways

The existing orders desk does not model temple doorways. IV.6 is unusually useful
for a new room: an opening, its casing and its height-dependent contraction are
different quantities. A supplied word changes both the opening and the applicable
contraction band. The learner should be able to make that consequence visible.

The room uses the existing marble (#eceee9), sheet (#f8f9f5), graphite (#1f2328),
Egyptian blue (#1f4e9c) and minium (#b3321f), with the existing dark equivalents.
GFS Didot titles and EB Garamond text remain local. Blue identifies the learner's
trial; red identifies the computed limit. Colour is accompanied by line styles
and text. No new fonts, photographs, dependencies or idle animation.

```

------------------------------------------------------------

Supplied half      |  ruler      /---------\   /---------\

                   |             |         |   |         |
Trial / rule       |  floor --------------------------------
------------------------------------------------------------
Opening / jamb / lintel / contraction: select a word or stone
What changes at 16, 25 and 30 feet?  [boundary comparisons]
Read the sentences beside the complete printed pages
Keep the drawing, measurements and illustrated reading
```

The two doors share a physical scale and ceiling. This is the memorable object;
the surrounding controls stay quiet. At narrow widths, the drawing keeps both
doors together and the controls precede it. A second, enlarged corner view makes
small tapers visible without stretching one axis.

Review against the brief: a collection of order cards would repeat the current
site. Instead the plate compares the numerical consequence of one supplied word.
The ruler encodes seven half-parts, rather than serving as decorative gridwork.
The manual trial gives the learner something to get wrong, inspect and change.

This is a reading experiment, not a reconstructed ancient doorway. Krohn p. 88
leaves a lacuna in the Doric casing instruction; using the Ionic casing width
for Doric is an explicit drawing assumption. The drawn lintel has a text-based
height; overdoor mouldings, consoles and door leaves are omitted. No optical
perception or structural performance is claimed. The two height readings are
not attributed to two uniform manuscript families.

## Survey comparison added after the audit

A second desk keeps the same graphite/blue/red palette and type. Its subject is
one reported opening: Stevens's Erechtheion survey, published in Paton's 1927
volume, pp. 98-99. The reported dimensions remain black; red measures a selected
proportional rule. A height/width alignment changes only the compared dimension.
The other dimension must retain its mismatch. The survey's "essentially" is
kept visible: 4.882 m is not exactly twice 2.427 m.

```
Almost a double square
---------------------------------------------------------
width rule / match height or lower width
[reported opening + one red dimension] | [remaining error]
                                       | [reported / derived table]
---------------------------------------------------------
complete p. 98 / p. 99, including the omitted later lining
```

The two sources remain distinct. The survey supplies metric dimensions of its
reported original opening; Vitruvius supplies dimensionless width relations.
There is no conversion of Roman feet and no inferred ancient ceiling height.
The ratio comparison does not predict the casing or upper opening width.
